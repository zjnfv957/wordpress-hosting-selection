# WordPress主機推薦：預算有限也能架站，從方案挑選、面板比較到實際安裝的完整判斷

會去搜「WordPress主機推薦」的人，十個裡有九個心裡想的其實不是「哪家最好」。真正卡住的地方比較具體：不確定自己的站需要多少資源、看不懂規格表上那些數字代表什麼、以及最實際的一點——怕買下去之後裝不起來，錢花了，網站還是空白。

所以這篇不從「十大主機排行榜」開始。先講你該租哪一層，再講低價位帶有哪些選擇、規格怎麼看，最後把安裝流程和容易踩到的坑一次列出來。

---

## 先確定你要租的是哪一層，再談品牌

WordPress 主機不是單一東西，而是四種完全不同的服務型態。搞錯這一層，後面比價都白比。

| 類型 | 你拿到什麼 | 誰維護系統 | 月費大概落在 |
| --- | --- | --- | --- |
| 共享／虛擬主機 | 一台機器切出來的空間，PHP + MySQL 環境現成 | 主機商全包，你只管後台 | 約 NT$100–300 |
| VPS | 獨立分配的 CPU、記憶體、硬碟 | 自己裝環境、自己顧資安 | 約 NT$200–1,500 |
| 雲端代管 | 獨立機器，底層由中間服務商處理 | 底層外包，WordPress 你自己顧 | 約 NT$350–1,500 |
| 全代管／SaaS 架站 | 主機、快取、備份、資安整包 | 主機商全包，你只寫內容 | NT$800 起，上看數千 |

判斷方法很簡單：如果你現在連 SSH 都沒開過，就不該從 VPS 起跳。很多部落客一開始買了獨立主機，結果一年下來用不到一成資源，等於每年多付幾千元在閒置規格上。反過來說，如果你的站已經在跑 WooCommerce、每天幾十筆訂單，硬撐在共享主機上只會換來當機。

### 看規格時，真正該問的三件事

大部分主機商的比較表都在寫「WordPress 專用最佳化」「一鍵安裝」這類詞，這些每家都寫得出來，也很難拿去比較。有三項是能問出具體答案的：

**PHP 版本能不能自己切。** WordPress 本體好解決，麻煩的是五年沒更新的外掛在新版 PHP 上直接白畫面。可用的 PHP 版本要能逐一列出，切換介面在哪、以網域還是子目錄為單位，這些都會影響你搬站時的停機時間。

**有沒有可用的快取機制。** WordPress 每開一次頁面就查一次資料庫，沒有快取的話流量一來速度直接掉。LiteSpeed、Redis 這類伺服器端快取比純外掛方案有效得多。

**同機其他網站會不會拖慢你。** 這是共享架構的先天限制，也是低價方案最常被抱怨的地方。

## 低價位帶的選擇：雨雲（RainYun）的虛擬主機在賣什麼

把預算壓在每月幾百元以內的話，可以看一下雨雲。它從 2018 年開始自研系統並營運，產品線包含雲伺服器、遊戲雲、物件儲存、CDN，以及這篇的主角——虛擬主機（官方叫 RVH，Rain Virtual Host）。中文介面、支援支付寶與微信付款，對中文使用者沒有語言門檻。

它的虛擬主機分成兩種面板，這一點比價格更值得先搞清楚。

**寶塔面板主機**走 LXD 容器化路線。CPU、記憶體、頻寬、硬碟都是獨享的，能用到完整的寶塔面板功能：不限網站數、不限資料庫與域名、支援 SSH／SFTP／MySQL 遠端連線、可以外接獨立 IP。官方文件直接建議所有使用者選寶塔主機，新手老手都適用。要跑 WordPress，這個是比較合理的選擇。

**EP 面板主機**用的是 EasyPanel（Kangle 那套），主打輕量。CPU 與記憶體是共享的，支援 PHP + MySQL，但單台主機限制綁定 5 個域名，只能掛一個資料庫。適合純靜態站或單一 PHP 站，不適合外掛裝得多、之後想擴充的 WordPress 站。

兩者都有的共通功能：免費定時自動備份、CC 防火牆、DDoS 自動防禦，以及隨時升級套餐（官方說一分鐘內完成）。

### 節點怎麼選，以及備案這件事

雨雲的虛擬主機節點分免備案與需備案兩類：

- **香港**：三網直連的 CN2 線路，官方標示的參考延遲約 88ms。頻寬小是它的代價。
- **美國洛杉磯 1 區**：國際大頻寬，官方標示參考延遲約 173ms。適合圖片多、流量大的免備案站。
- **中國大陸節點**：官方標示參考延遲約 25ms，附帶高防，但**用域名架站必須先完成第三方備案**。

如果你只是要架個人部落格，香港或洛杉磯就夠了，不必碰備案流程。另外官方說明所有虛擬主機流量不限，這對圖片較多的 WordPress 站算實用。

## 用寶塔面板裝 WordPress：流程與四個容易卡住的點

買完之後的實際操作，官方有一步一步的引導，但第一次碰的人常在這幾處停住。

1. **先在寶塔面板建立網站**，設定好 root 目錄與 PHP 版本，再上傳 WordPress 安裝包。
2. **到雨雲的控制台補做一次域名綁定**。這是關鍵：寶塔裡綁了不等於生效，雨雲面板也要綁一次，漏掉這步的症狀是「設定都對，但網站打不開」。
3. **資料庫連線填 127.0.0.1、埠 3306**。雨雲面板顯示的那個遠端 MySQL 埠是給 Navicat 之類外部工具用的，WordPress 的 `wp-config.php` 要填本地埠，填錯會卡在資料庫連線失敗那一步。
4. **裝完先把固定連結、SSL、快取設定處理好**，再開始寫文章。之後改永久連結會更麻煩。

### 幾個購買前就該知道的限制

- **共享 IP、只能用固定埠。** 所以 phpMyAdmin 的預設 888 埠要改成雨雲面板顯示的埠才能進；想要完整埠權限得另外加購獨立 IP。有評測提到獨立 IP 約每月 4.68 元、週期與主機相同，實際價格以官網為準。
- **不支援 IPv6。** 第三方實測香港寶塔二代高配版時提到這一點，如果你的訪客或服務鏈路有 IPv6 需求，要先納入考慮。
- **不要在寶塔面板裡升級或修復寶塔本體。** 官方文件自己也這樣建議，出問題要用雨雲的修復主機功能處理。
- **後台與客服都是簡體中文。** 不影響使用，但如果你是習慣繁體介面的使用者，這點要有心理準備。

## 價格以外，幾個會影響實際支出的變數

**長期付費折扣可以疊。** 官方針對長期付款提供季付 9 折、半年付 8 折、年付 7 折。而新用戶透過專屬連結註冊，通常會拿到首月 5 折券（常見說法是要先綁定微信領取）。把優惠券和年付折扣疊在一起，實際單價會比標價低一截。比較務實的做法是先用折扣買一個月實測，穩定再轉年付。

**消費會返積分。** 購買或續費可拿到消費金額 10%–20% 的積分返還，積分能在官方積分商城換優惠券，也支援提現。每日簽到、綁定微信郵箱等小任務也會給積分。

**有 7 天無理由退訂。** 這點對「先試一個月看看」的做法很重要，但特價方案的條款可能較嚴，購買前務必自己讀一次退款政策全文。

**該知道的缺點也講清楚。** 第三方評測與中文問答平台上的抱怨大致集中在三塊：低價方案的 CPU、記憶體與 I/O 限制偏緊，流量突然來一波或外掛裝得多就容易觸頂；共享 IP 帶來的埠限制；以及工單回應速度在非工作時段不算快。這些回饋是針對整個低價虛擬主機價位帶的，不是雨雲獨有，但選方案時值得一併考量。反過來看，也有評測實測香港寶塔二代高配版，UnixBench 單核約 630 分、多核約 886 分，4K 隨機讀寫約 9.75 MB/s——以這個價位來說稱得上堪用。

## 常見問題

**5 元的入門方案能跑 WordPress 嗎？**
能裝起來，但 512MB 記憶體同時扛面板、MySQL 和 PHP，外掛一多就會明顯變慢。除非你的站只有幾頁靜態內容，否則建議從 2 核 2G 起。

**香港還是美國洛杉磯？**
訪客主要在台灣或亞洲，香港的延遲較低但頻寬較小；如果你的站圖片多、流量大又不需要低延遲，洛杉磯 1 區的大頻寬更划算。真不確定就先買一個月實測。

**需要自己會寫程式嗎？**
不需要。寶塔面板預裝 LNMP，WordPress 有官方安裝引導，真正需要技術判斷的地方主要是 PHP 版本選擇與資料庫設定。遇上超出基礎範圍的問題，客服支援的深度有限，這點要先知道。

**價格是人民幣，付款方便嗎？**
支援支付寶與微信付款，對中文使用者來說流程單純。標價是人民幣，換算成台幣時記得把匯率與可能的刷卡手續費一起算進去。
